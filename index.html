🎛 Web MIDI & DAW Integration Overview

Gesture Synth transforms your webcam hand movements into real-time Web MIDI messages (polyphonic MIDI Note-On/Off & Continuous Controller CCs) to trigger any software synthesizer or DAW plugin (Ableton Live, FL Studio, Logic Pro, Reaper, Cubase, Bitwig).

🪟 Windows Setup Guide (Virtual MIDI via loopMIDI)

  1. Download loopMIDI: Download & install the free utility loopMIDI by Tobias Erichsen.
  2. Create Virtual Port: Open loopMIDI, click the + button at the bottom left to create a virtual port (e.g. loopMIDI Port).
  3. Enable Output in App: Open Gesture Synth in Chrome/Edge, click ⚙ Settings → Audio & MIDI, check Enable Web MIDI Output, and select loopMIDI Port as the target output.
  4. Configure DAW Input: Open your DAW (Ableton, FL Studio, Reaper), go to Preferences → MIDI, and enable loopMIDI Port as an active MIDI Input device.
  5. Arm Instrument Track: Create a Synth / VST track in your DAW, set its MIDI input to loopMIDI Port (Channel 1), and arm the track for recording!

🎚 MIDI CC Mapping & DAW "MIDI Learn"

  • Right Hand Tilt (CC 1 ModWheel): Right-click any plugin knob (Filter Cutoff, Resonance, Effects) in your DAW, click MIDI Learn, and tilt your hand to map it instantly.
  • Right Hand Height (CC 7 Volume): Controls expression / master gain vertically.
  • Tilt Modes: Choose between Normal (Center = 50%) or Bipolar (Center = Min, Right = +, Left = -) in Right Hand settings.
  • Left Hand Chord Mode: Sends the same chord that plays in Web Audio Mode as MIDI.
  • Left Hand Single Mode: Sends single note in the selected key

⚡ Troubleshooting Tips

  • No signal in DAW? Ensure loopMIDI or IAC Driver is created and running before launching your DAW.
  • Browser popup block? Make sure to click the startup screen to initialize Web Audio and grant Web MIDI permissions when prompted.
